실제 지도 좌표를 기반으로 후보 지역을 표시합니다. 시나리오를 바꾸면 마커의 순위도 함께 변경됩니다.

확대 후보 현재 1순위
지도 바탕은 OpenStreetMap을 사용하며, 후보 지역은 동·읍 단위 실제 위치를 기준으로 표시했습니다. 지역명이 중복될 수 있어 상위 행정구역을 함께 표기합니다. KCP 비교 페이지 ↗
새 창에서 KCP 열기 ↗
KCP 사이트가 보안 설정(X-Frame-Options/CSP)으로 외부 사이트 내 삽입을 제한하는 경우 iframe이 표시되지 않을 수 있습니다. 그때는 우측 상단의 ‘새 창에서 KCP 열기’를 이용하면 됩니다.

후보 지역 현황

동·읍·면 후보지를 확인하고 KCP 데이터를 연결해 추가합니다.

동·읍·면을 검색해 실제 법정동을 선택하면 행정코드를 KCP API에 전달하고, 월별 배출량으로 v3 지표를 자동 계산해 후보에 추가합니다.
KCP 데이터 자동 조회
지역 확인이 끝나면 연결된 KCP 월별 데이터에서 해당 지역을 자동 검색하고, 탄소 v3의 계산식을 이용해 최근 12개월 평균배출량·Trend 기울기·YoY 증가월 비율을 바로 계산합니다.
※ 기본 KCP 후보는 유지되며, 사용자가 직접 추가한 후보지역만 ‘후보 삭제’ 버튼으로 제거할 수 있습니다.

시나리오별 정책 제언

시나리오의 정책 목적과 v3 순위 결과를 함께 해석합니다.

전국 후보 자동조회: 후보지역 검색은 법정동 코드 목록을 사용하고, KCP 월별 데이터는 서버에서 https://api.korea-carbon-project.org/region/compare/monthly 엔드포인트로 요청합니다. 현재 분석기간은 v3와 동일한 2020.01~2022.12입니다. KCP 응답으로부터 최근 12개월 평균, STL Trend 기울기, YoY 증가월 비율을 계산합니다.
KCP 지표 선택: 현재 기본 6개 후보지역 원본이 연결된 지표는 ‘에너지 제조업 및 건설업 탄소 배출량’입니다. 농업·폐기물 지표를 선택하면 해당 KCP metric의 월별 데이터만 사용하여 서로 다른 지표의 데이터가 섞이지 않도록 구성했습니다.
데이터 해석 주의: 이 화면의 후보 순위와 민감도 결과는 ‘탄소 v3’의 세 지표(배출수준·최근추세·반복증가) 및 시나리오 가중치에 기반합니다. 기본 후보지역은 제공된 KCP Excel과 탄소 v3 결과를 사용합니다. 사용자가 추가하는 후보지역도 동일한 세 지표와 시나리오 가중치로 다시 정규화·순위화됩니다. 후보 지도는 실제 지형을 보여주기 위해 OpenStreetMap을 사용하고, KCP 원본 비교 페이지를 별도 탭으로 연결했습니다.
